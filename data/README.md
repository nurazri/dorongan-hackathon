# Local match data

Keep the organiser's authorised match bundle here, or point the direct exporter at another data directory. Asset files are ignored by Git; only this README is published.

[Dorongan.md](../Dorongan.md#install-and-reproduce-the-csv) lists the three tactical files needed to reproduce the submission. Its [viewer instructions](../Dorongan.md#install-and-run-the-angular-viewer) explain how to configure the complete nine-file bundle using `lab/setup_data.py`.

Preserve the bundle's `tactical/` and `broadcast/` subfolders and original filenames. [DATA.md](../DATA.md) describes every format and timeline. The videos and tracking are separately licensed competition assets; keep them out of the public repository.
